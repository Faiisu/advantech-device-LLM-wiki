# ARK-3532B

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Date:** N/A  
**Origin:** `raw/ark-3000series/ARK-3532B.md` | https://www.advantech.com/th-th/products/1-2jkd2d/ark-3532b/
**Sub-series:** [[ARK-3532x]]

## Summary

The ARK-3532B is a 10th Gen Intel Xeon W / Core i LGA1200 expansion fanless box PC. Supports up to Xeon W-1290TE (10-core, 35W) with ECC DDR4 64GB. Key differentiator over ARK-3532C: a PCIe x16 graphics card slot enables discrete GPU deployment in a fanless chassis. Also includes TPM 2.0, lockable USB ports, and a full SW bundle (WISE-DeviceOn, SUSI API, McAfee, Acronis). Targets high-performance AI edge inference, machine vision, and compute-intensive industrial applications.

## Key Points

- **CPU:** Xeon W-1290TE / Core i9-10900E / i7-10700E / i5-10500E / i3-10100E / Celeron G5900E; LGA1200; Intel W480E chipset
- **Memory:** DDR4 2933MHz, up to 64 GB, 2× 260-pin SO-DIMM; ECC supported (by processor)
- **Display:** VGA + HDMI + optional 3rd display module
- **LAN:** 4× GbE — Intel I219-LM + 3× Intel I210; all Wake-on-LAN
- **COM:** 6× — 2× RS-232 + 4× RS-232/422/485
- **USB:** 8× — 4× USB 3.2 Gen2 (10 Gbps) + 2× USB 3.0 + **2× independent lockable USB 3.0**
- **GPIO:** 16-bit DIO
- **TPM:** 2.0
- **Expansion:** 1× full-size Mini PCIe (shared mSATA + SIM holder), 1× M.2, 1× PCIe x4, **1× PCIe x16 graphics card slot**
- **Storage:** 1× mSATA (shared Mini PCIe), 2× 2.5" SATAIII (up to 4× with optional bays); Intel SW RAID supported
- **Power:** AT/ATX, 9~36 VDC wide-range; typical 30W, max 64.8W
- **Temp:** -20~60°C (extended-temp peripherals + 0.7 m/s airflow); 0~40°C with HDD
- **OS:** Windows 10/11 IoT Enterprise LTSC; Linux by project
- **Cert:** CE/FCC Class B, CCC, BSMI; CB, UL, CCC, BSMI
- **SW:** SUSI API, WISE-DeviceOn, McAfee, Acronis bundled
