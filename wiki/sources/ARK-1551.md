# ARK-1551

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Origin:** `raw/ARK-1551.md` | https://www.advantech.com/th-th/products/1-2jkbyz/ark-1551/

## Summary

Slim fanless computer on Intel 8th Gen Core i5-8365UE or Celeron 4305UE (Whiskey Lake-U). Not a DIN-rail-first design — **wall mount is default**, DIN-rail optional. Notable: **4× USB 3.1 Gen2**, swappable 2.5" SATA bay (hot-swap capable), Intel software RAID 0/1, NVMe storage support via SQF PCIe×2 adapter, RED certified for WiFi/BT/LTE, TPM 2.0, case-open detection, and slim 55mm height.

## Key Specs

- **CPU:** Intel Core i5-8365UE (4c/1.6 GHz, burst 4.1 GHz) | Celeron 4305UE (2c/2.0 GHz); Whiskey Lake-U
- **Memory:** DDR4 2400 MHz, up to 32 GB, 2× 260-pin SO-DIMM
- **Display:** 1× HDMI (4K) + 1× VGA; dual independent
- **GPU:** Intel UHD 620 (i5) / HD 610 (Celeron); DirectX 12, OpenCL 2.1
- **Ethernet:** 2× GbE (Intel i210 + i219)
- **Serial:** **4× RS-232/422/485** (50 bps to 921.6 kbps); COM3 with 5V/12V power (jumper)
- **USB:** **4× USB 3.1 Gen2** (Type A)
- **GPIO:** 8-bit
- **Storage:** 1× swappable 2.5" SATAIII bay (7mm); 1× full-size mSATA (shares mPCIe); NVMe via SQF PCIex2 adapter
- **Expansion:** 1× full-size mPCIe with nano SIM; 1× M.2 2230 E key
- **Security:** TPM 2.0 (Infineon SLB9665XQ); case-open detection
- **Power:** 12–24 VDC; 90–120W adapter; typical **8.93W** (Celeron) / **13.87W** (i5); max 24.7W / 47.12W
- **Operating temp:** -20–55°C (extended, with SSD); 0–40°C with HDD
- **Dimensions:** 195 × 55 × 140 mm; 1.2 kg
- **Mounting:** Wall (default); VESA and DIN-Rail optional
- **OS:** Windows 10; Ubuntu
- **Certifications:** **RED certified** (WiFi/BT/LTE)

## Differentiators vs. ARK Series

- **USB 3.1 Gen2** (10 Gbps) — fastest USB in the series
- **Swappable** 2.5" drive bay — field-replaceable storage without power-down
- **Software RAID 0/1** — data redundancy in a fanless edge device
- **NVMe support** via SQF PCIex2 — highest storage bandwidth option in ARK series
- **RED certified** for wireless (unlike most ARK models)
- **Case-open detection** — physical security tamper notification
- Wall-mount first, not DIN-rail primary — different deployment context
