# ARK-1123H

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Origin:** `raw/ARK-1123H.md` | https://www.advantech.com/th-th/products/1-2jkbyz/ark-1123h/  
**Sub-series:** [[ARK-1123x]]

## Summary

Fanless box PC on Intel Celeron J1900 (same CPU as ARK-10, ARK-6322) but with dual HDMI instead of VGA — the "H" suffix denotes HDMI-focused display output. IoT-oriented with SUSIAccess API support. FCC/RED certification available via the AMO-WIFI08E optional WiFi module. Same compact form factor as ARK-10.

## Key Specs

- **CPU:** Intel Celeron J1900, 4-core, 2.0 GHz (burst 2.41 GHz)
- **Memory:** DDR3L 1333 MHz, up to 8 GB, 1× SO-DIMM
- **Display:** 2× independent HDMI (no VGA)
- **Ethernet:** 2× Intel i210 GbE (Wake on LAN)
- **Serial:** 2× RS-232/422/485 (BIOS selectable)
- **USB:** 1× USB 3.0 + 2× USB 2.0
- **Storage:** 1× 2.5" SATA HDD Bay (max 9.5mm height); 1× half-size mSATA
- **Expansion:** 1× full-size Mini PCIe (WLAN or WWAN)
- **Power:** 12 VDC; 36W adapter (threaded DC jack); typical **5.64W**, max 14.04W
- **Operating temp:** -20–60°C with extended temp SSD/RAM; 0–40°C with standard peripherals
- **Dimensions:** 133.8 × 43.1 × 94.2 mm
- **Mounting:** VESA / DIN Rail / Wall (optional)
- **OS:** Windows 10 IoT 64-bit; Linux by project
- **Software:** Supports SUSIAccess and Embedded Software APIs
- **Certifications:** FCC/RED available with AMO-WIFI08E module

## Differentiators vs. ARK Series

- Dual HDMI (vs. VGA on ARK-10) — targets display-output use cases
- SUSIAccess API — Advantech's embedded software management layer
- RED certification path via optional WiFi module (ARK-10 has no RED path)
- Lower typical power than ARK-10 (5.64W vs. not stated)
