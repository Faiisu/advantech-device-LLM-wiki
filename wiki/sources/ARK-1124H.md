# ARK-1124H

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Origin:** `raw/ARK-1124H.md` | https://www.advantech.com/th-th/products/1-2jkbyz/ark-1124h/  
**Sub-series:** [[ARK-1124x]]

## Summary

DIN-rail fanless box PC on Intel Atom E3940 (Apollo Lake, quad-core). Dual HDMI 4K display, dual GbE, 4× USB 3.0, TPM 2.0 built-in, M.2 E key for WiFi, and iDoor compatibility. RED certification available via AMO-WIFI10 module (single-layer SKU only). WISE-DeviceOn supported. Targets display-centric IoT deployments requiring security.

## Key Specs

- **CPU:** Intel Atom E3940, 4-core, 1.6 GHz (burst 1.8 GHz); Apollo Lake
- **Memory:** DDR3L 1866 MHz, up to 8 GB, 1× SO-DIMM
- **Display:** 2× HDMI (4K2K independent); Intel HD Graphics 500
- **Ethernet:** 2× Intel i210 GbE (Wake on LAN)
- **Serial:** 1× RS-232/422/485 (auto flow control)
- **USB:** 4× USB 3.0
- **GPIO:** via iDoor (not built-in)
- **Storage:** 1× 2.5" SATA HDD Bay (max 9.5mm); 1× half-size mSATA
- **Expansion:** 1× full-size mPCIe with nano SIM holder; 1× M.2 E key (WiFi); iDoor (2nd layer)
- **Security:** TPM 2.0 (Infineon SLB9665XQ)
- **Power:** 12 VDC; 60W adapter (lockable DC jack); typical **6.02W**, max 15.7W
- **Operating temp:** -20–60°C (extended); 0–40°C with HDD
- **Dimensions:** 133 × 46.4 × 94.2 mm; 0.7 kg
- **Mounting:** DIN-Rail / Wall / VESA
- **OS:** Windows 10; Linux by project
- **Certifications:** CE/FCC Class B; UL/CB 62368; RED available with AMO-WIFI10 (single-layer SKU)

## Differentiators vs. ARK Series

- **TPM 2.0** — first model in this series with hardware security module
- Dual HDMI 4K — better display quality than VGA-only models
- RED certification possible — unlike many ARK-1000 models
- Only **1× COM port** — trade-off for USB/display richness
- iDoor + M.2 E key gives dual wireless expansion path
