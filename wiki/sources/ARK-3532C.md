# ARK-3532C

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Date:** N/A  
**Origin:** `raw/ark-3000series/ARK-3532C.md` | https://www.advantech.com/th-th/products/1-2jkd2d/ark-3532c/
**Sub-series:** [[ARK-3532x]]

## Summary

The ARK-3532C shares the same 10th Gen Intel Xeon W / Core i LGA1200 platform as the ARK-3532B but targets legacy PCI integration rather than GPU expansion. Replaces the PCIe x16 graphics slot with 2× PCI slots, making it suited for installations using older PCI-based I/O boards or fieldbus cards. No TPM or SW bundle listed. Available in two SKUs: 00A1 (6× COM) and 00A1U (4× COM).

## Key Points

- **CPU:** Xeon W-1290TE / Core i9-10900E / i7-10700E / i5-10500E / i3-10100E / Celeron G5900E; LGA1200; Intel W480E chipset
- **Memory:** DDR4 2933MHz, up to 64 GB, 2× 260-pin SO-DIMM; ECC supported (by processor)
- **Display:** VGA + HDMI + optional 3rd display module
- **LAN:** 4× GbE — Intel I219-LM + 3× Intel I210
- **COM:** **6× (00A1)** — 2× RS-232 + 4× RS-232/422/485 | **4× (00A1U)** — 2× RS-232 + 2× RS-232/422/485
- **USB:** 8× — 4× USB 3.2 Gen2 (10 Gbps) + 2× USB 3.0 + 2× independent USB 3.0
- **GPIO:** 16-bit
- **Expansion:** 1× full-size Mini PCIe (shared mSATA + SIM), 1× M.2, **2× PCI**, 1× PCIe x4 (no PCIe x16)
- **Storage:** 1× mSATA (shared Mini PCIe), 2× 2.5" SATAIII
- **Power:** AT/ATX, 9~36 VDC; typical 30W, max 64.8W
- **Temp:** -20~60°C (extended temp); 0~40°C (00A1) / 0~45°C (00A1U) with HDD
- **OS:** Windows 10/11 IoT Enterprise LTSC; Linux by project
- **Cert:** Not explicitly listed in spec sheet
- **RED:** No RED Certification
