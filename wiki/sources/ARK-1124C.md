# ARK-1124C

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Origin:** `raw/ARK-1124C.md` | https://www.advantech.com/th-th/products/1-2jkbyz/ark-1124c/  
**Sub-series:** [[ARK-1124x]]

## Summary

DIN-rail fanless box PC on Intel Celeron N3350 (Apollo Lake, dual-core). Distinguishing features: **4× RS-232/422/485 serial ports** (double the typical 2-port baseline), Advantech iDoor module compatibility (2nd expansion layer), optional 12–24V power module. Targets serial-heavy field deployments. No RED certification.

## Key Specs

- **CPU:** Intel Celeron N3350, 2-core, 1.1 GHz (burst 2.4 GHz); Apollo Lake
- **Memory:** DDR3L 1866 MHz, up to 8 GB, 1× SO-DIMM
- **Display:** 1× VGA; Intel HD Graphics 500
- **Ethernet:** 1× Intel i210 GbE (single LAN — notable limitation)
- **Serial:** **4× RS-232/422/485** with auto flow control
- **USB:** 2× USB 3.0
- **Storage:** 1× 2.5" SATA HDD Bay (max 9.5mm); 1× half-size mSATA
- **Expansion:** 1× full-size mPCIe (WLAN/WWAN); 1× iDoor slot (2nd layer, optional)
- **Power:** 12 VDC; 36W adapter (lockable DC jack); typical **5.5W**, max 10.2W
- **Operating temp:** -20–60°C (extended temp); 0–40°C with HDD
- **Dimensions:** 133 × 46.4 × 94.2 mm; 0.7 kg
- **Mounting:** DIN-Rail / Wall / VESA (optional)
- **OS:** Windows 10; Linux by project
- **Certifications:** CE/FCC Class B; UL/CB 62368; **no RED**

## Differentiators vs. ARK Series

- **4× COM ports** — highest serial port count in the DIN-rail compact tier
- **Single GbE** — only one LAN port (most others have 2) — constraint for network-isolated deployments
- iDoor module support — can expand I/O via optional 2nd layer (CAN, fieldbus, wireless)
- Lockable DC jack — field-deployment resistant to accidental disconnection
