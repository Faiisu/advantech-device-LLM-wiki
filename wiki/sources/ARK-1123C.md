# ARK-1123C

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Origin:** `raw/ARK-1123C.pdf` | https://www.advantech.com/th-th/products/1-2jkbyz/ark-1123c/  
**Sub-series:** [[ARK-1123x]]

## Summary

Compact fanless box PC on Intel Atom E3825 (Bay Trail-M, dual-core, 1.33 GHz). Lower-spec sibling to the J1900-based models in the same form factor. Key differentiators: **-30~70°C operating range** with extended temp peripherals (wider than ARK-10 and ARK-1123H despite older CPU), dual Intel i210 GbE, WISE-DeviceOn supported. Minimal I/O — no GPIO, only 3 USB ports. CE/FCC **Class B** — cleared for both residential and industrial use.

## Key Specs

- **CPU:** Intel Atom E3825, 2-core, 1.33 GHz; Bay Trail-M; L2 Cache 1 MB
- **Memory:** DDR3L 1066 MHz, up to 8 GB, 1× 204-pin SO-DIMM
- **Display:** 1× VGA (up to 1920×1200 @ 60Hz)
- **GPU:** Intel Atom SoC integrated; DirectX 11.1, OGL 3.0, OCL 1.1
- **Ethernet:** 2× Intel i210 GbE (Wake on LAN)
- **Serial:** 2× RS-232/422/485 (BIOS selectable)
- **USB:** 2× USB 2.0 + 1× USB 3.0
- **GPIO:** None
- **Storage:** 1× 2.5" SATA HDD Bay (max 9.5mm); 1× half-size mSATA
- **Expansion:** 1× full-size Mini PCIe (WLAN/WWAN — hardware interface only, no RF certification)
- **Power:** 12 VDC; 36W adapter (threaded DC jack); typical **5.28W**, max 8.16W
- **Operating temp:** -30–70°C (with extended temp SSD/mSATA/RAM); 0–40°C with standard peripherals
- **Dimensions:** 133.8 × 43.1 × 94.2 mm; 0.8 kg
- **Mounting:** VESA / DIN Rail / Wall (optional)
- **OS:** Windows 10; Linux by project; Windows 10 IoT Enterprise 2019 LTSC available (OEM/CTOS)
- **Software:** WISE-DeviceOn and Embedded Software APIs
- **Certifications:** CE/FCC Class B, CCC, BSMI, UKCA; UL, CCC, CB, UKCA

## Notable Details

- Mini PCIe is hardware interface only — **no system-level RF certification available**
- UKCA certification included — compliant for UK market post-Brexit
- Lowest-spec CPU in the ARK-1123 sub-series (E3825 dual-core vs J1900 quad-core in ARK-1123H)
- Despite older CPU, -30~70°C range exceeds ARK-1123H's -20~60°C

## Differentiators vs. ARK-1123L (same CPU, same form factor)

| Feature | ARK-1123C | ARK-1123L |
|---|---|---|
| GbE ports | **2×** | 1× |
| Serial ports | 2× RS-232/422/485 | 1× RS-232 + 1× RS-232/422/485 |
| USB 2.0 | **2×** | 1× |
| GPIO | None | **8-bit** |
| EMC class | **Class B** (residential + industrial) | Class A (industrial only) |
