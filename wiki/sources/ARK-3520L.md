# ARK-3520L

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Date:** N/A  
**Origin:** `raw/ark-3000series/ARK-3520L.md` | https://www.advantech.com/th-th/products/1-2jkd2d/ark-3520l/

## Summary

The ARK-3520L is a 6th Gen Intel Core i5/i7 (Skylake-H BGA) modular expansion fanless box PC. Desk/wall-mount form factor (220×101×233mm) — roughly 3× the volume of an ARK-1123x. Supports triple independent display, 8× COM ports, 16-bit GPIO, iDoor, and the ARK Plus AMO-3xxx riser card system (adds 2× PCI + 1× PCIe x4). Targeted at edge applications requiring high per-core performance, multi-COM integration, and flexible I/O expansion.

## Key Points

- **CPU:** Intel Core i5-6440EQ (2.7 GHz, 4C, 45W) or i7-6820EQ (2.8 GHz, 4C, 45W); BGA; Intel QM170 chipset
- **Memory:** DDR4 2133MHz, up to 32 GB, 2× 260-pin SO-DIMM; no ECC
- **Display:** Triple independent — VGA + HDMI + optional 3rd (DVI-D / DP / 2nd HDMI via display module)
- **LAN:** 2× GbE — Intel I219-LM + Intel I210; both Wake-on-LAN
- **COM:** 8× total — 4× RS-232 + 4× RS-232/422/485 auto-flow; COM1/2 support 5V/12V power on pin
- **USB:** 6× USB 3.0 + 2× USB 2.0
- **GPIO:** 16-bit
- **Expansion:** 2× full-size Mini PCIe (#1 shared with mSATA + SIM holder), 1× M.2, iDoor module slot, EMIO miniPCIe, ARK Plus AMO-3xxx riser (AMO-3501E: 2× PCI + 1× PCIe x4)
- **Storage:** 1× mSATA (shared Mini PCIe #1), 1× 2.5" SATAIII (up to 15mm height)
- **Power:** 12 VDC, AT/ATX; 150W AC-DC adapter optional; typical 11.4W, max 46.5W (i5) / 68.4W (i7)
- **Dimensions:** 220×101×233mm (8.66×3.98×9.17 in), 4.8 kg
- **Mounting:** Desk/wall-mount (not DIN-rail)
- **Temp:** -20~60°C with extended-temp peripherals + 0.7 m/s airflow; 0~40°C with HDD
- **OS:** Windows 10/8.1/7; Linux by project
- **RED:** No RED Certification
- **Watchdog:** 255-level software-programmable
