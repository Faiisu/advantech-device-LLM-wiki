# ARK-1250L

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Origin:** `raw/ARK-1250L.md` | https://www.advantech.com/th-th/products/1-2jkbyz/ark-1250l/

## Summary

DIN-rail fanless box PC on **Intel 11th Gen Core i5-1145G7E / i3-1115G4E** (Tiger Lake-UP3). The highest-performance model in the ARK-1000 series reviewed — full Core i-class CPU, **3–4× GbE ports**, **4× RS-232/422/485**, DDR4 up to 64 GB, -40–60°C, and optional CAN Bus. Targets compute-intensive industrial applications (WISE-DeviceOn AI deployment support).

## Key Specs

- **CPU:** Intel Core i5-1145G7E (4c/1.5 GHz, burst TBD) | Core i3-1115G4E (2c/2.2 GHz); Tiger Lake
- **Memory:** DDR4 3200 MHz, up to **64 GB**, 2× 260-pin SO-DIMM
- **Display:** 1× HDMI (4K) + 1× VGA (standard); dual HDMI in some SKUs
- **Ethernet:** 3× GbE (Intel i225 2.5G + Intel i219 1G + Intel i225 2.5G); some SKUs 4× GbE
- **Serial:** **4× RS-232/422/485**
- **CAN Bus:** 1× optional (DB9 connector, CAN 2.0)
- **USB:** 2× USB 3.2 + 2× USB 2.0 + 1× internal USB 2.0 (security dongle)
- **GPIO:** 8-bit
- **Storage:** 1× 2.5" SATAIII Drive bay (9.5mm max); 1× full-size mSATA/mPCIe; 2× M.2
- **Security:** TPM optional (AMO-I029)
- **Power:** 12–24 VDC; 90W adapter; typical **18–19.8W**, max 30.6–35.1W
- **Operating temp:** -40–60°C
- **Dimensions:** 60 × 173 × 141 mm; 1.5 kg
- **Mounting:** DIN-rail / Wall
- **OS:** Windows 10/11 IoT Enterprise LTSC; Ubuntu 20.04
- **Software:** WISE-DeviceOn (AI deployment at scale)

## Differentiators vs. ARK Series

- **Highest-performance CPU** in this wiki — full 11th gen Core i-series (vs Atom/Celeron in others)
- **64 GB DDR4** — most memory capacity of any ARK reviewed
- **Triple/Quad GbE** — unique multi-port networking for routing/firewall use cases
- **4× COM + optional CAN Bus** — richest combined serial + vehicle bus I/O
- Larger chassis (60×173×141 mm) than slim DIN models — physically bigger
