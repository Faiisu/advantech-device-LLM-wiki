# ARK-1123L

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Origin:** `raw/ARK-1123L.pdf` | https://www.advantech.com/th-th/products/1-2jkbyz/ark-1123l/  
**Sub-series:** [[ARK-1123x]]

## Summary

Compact fanless box PC on Intel Atom E3825 (Bay Trail-M, dual-core, 1.33 GHz). The "L" (lower I/O) variant vs. ARK-1123C: trades one GbE port and one USB port for **8-bit GPIO**. Notable: CE/FCC **Class A** certification only — industrial environments, not cleared for residential. Same wide -30~70°C range. Despite the "palm-size" in the marketing title, dimensions are identical to ARK-1123C and ARK-1123H (133.8×43.1×94.2mm).

## Key Specs

- **CPU:** Intel Atom E3825, 2-core, 1.33 GHz; Bay Trail-M; L2 Cache 1 MB
- **Memory:** DDR3L 1066 MHz, up to 8 GB, 1× 204-pin SO-DIMM
- **Display:** 1× VGA (up to 1920×1200 @ 60Hz)
- **GPU:** Intel Atom SoC integrated; DirectX 11.1, OGL 3.0, OCL 1.1
- **Ethernet:** 1× Intel i210 GbE (Wake on LAN) — single LAN only
- **Serial:** 1× RS-232 (fixed) + 1× RS-232/422/485 (BIOS selectable)
- **USB:** 1× USB 2.0 + 1× USB 3.0
- **GPIO:** **8-bit**
- **Storage:** 1× 2.5" SATA HDD Bay (max 9.5mm); 1× half-size mSATA
- **Expansion:** 1× full-size Mini PCIe (WLAN/WWAN); 1× half-size Mini PCIe (mSATA)
- **Power:** 12 VDC; 36W adapter (threaded DC jack); typical **5.28W**, max 8.16W
- **Operating temp:** -30–70°C (with extended temp SSD/mSATA/RAM); 0–40°C with standard peripherals
- **Dimensions:** 133.8 × 43.1 × 94.2 mm; 0.8 kg
- **Mounting:** VESA / DIN Rail / Wall (optional)
- **OS:** Windows 10; Linux by project; Windows 10 IoT Enterprise 2019 LTSC available (OEM/CTOS)
- **Software:** WISE-DeviceOn and Embedded Software APIs
- **Certifications:** CE/FCC **Class A**, CCC, BSMI, UKCA; UL, CCC, CB, UKCA

## Notable Details

- **CE/FCC Class A** — industrial-environment certification only; **not cleared for residential use**
- COM1 is fixed RS-232 (not configurable); COM2 is RS-232/422/485 (BIOS selectable)
- Mini PCIe slot is hardware interface only — no system-level RF certification
- "Palm-size" in product title is marketing copy — actual dimensions identical to ARK-1123C
- Two Mini PCIe slots (1× full-size + 1× half-size) — more expansion than ARK-1123C's single slot

## Differentiators vs. ARK-1123C (same CPU, same form factor)

| Feature | ARK-1123L | ARK-1123C |
|---|---|---|
| GbE ports | **1×** | 2× |
| Serial ports | 1× RS-232 fixed + 1× RS-232/422/485 | 2× RS-232/422/485 |
| USB 2.0 | **1×** | 2× |
| GPIO | **8-bit** | None |
| Mini PCIe slots | **2×** (full + half) | 1× (full only) |
| EMC class | **Class A** (industrial only) | Class B (residential + industrial) |
