# ARK-1221L

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Origin:** `raw/ARK-1221L.md` | https://www.advantech.com/th-th/products/1-2jkbyz/ark-1221l/

## Summary

DIN-rail fanless box PC available in four CPU variants: Intel Atom x6413E (quad-core, -40–60°C), Intel Celeron J6412 (quad-core), and Intel Celeron N6210 (dual-core). First ARK model in this wiki on the **Elkhart Lake** platform with **DDR4 3200 MHz up to 32 GB**, dual 2.5GbE (Intel i225), HDMI + DisplayPort dual 4K display, 1× CAN Bus, and -40–60°C operation in the x6413E variant.

## Key Specs

- **CPU:** Intel Atom x6413E (4c/1.5GHz) | Celeron J6412 (4c/1.5GHz) | Celeron N6210 (2c/1.2GHz); Elkhart Lake
- **Memory:** DDR4 3200 MHz, up to **32 GB**, 2× 260-pin SO-DIMM
- **Display:** 1× HDMI (4K) + 1× DisplayPort (4K); dual independent display
- **Ethernet:** 2× Intel i225 **2.5GbE** (Wake on LAN)
- **Serial:** 2× RS-232/422/485 with auto flow control
- **CAN Bus:** 1× CAN Bus
- **USB:** 2× USB 3.2 + 2× USB 2.0 + 1× internal USB 2.0 (security dongle)
- **GPIO:** 8-bit
- **Storage:** 1× 2.5" SATAIII Drive bay (15mm); 1× full-size mSATA/mPCIe; 2× M.2; 1× full-size mPCIe
- **Security:** TPM optional (AMO-I029 module)
- **Power:** 12–28 VDC wide range; 60W adapter; typical **9.6W**, max 18.96W
- **Operating temp:** x6413E: **-40–60°C**; N6210: -20–60°C; others: -40–60°C
- **Dimensions:** 60 × 158 × 114 mm; 1.5 kg
- **Mounting:** DIN-rail / Wall
- **OS:** Windows 10; Ubuntu 20.04
- **Certifications:** no RED

## Differentiators vs. ARK Series

- **-40°C operation** (x6413E variant) — coldest operating spec in this wiki
- **DDR4 up to 32 GB** — double the memory capacity of E3940/N3350 models
- **HDMI + DisplayPort** — only model with DP output (vs HDMI+HDMI or HDMI+VGA elsewhere)
- Internal USB 2.0 for security dongle — dedicated hidden port for license keys
- 1× CAN Bus (vs 2× in ARK-1125H)
