# MIC-760

**Type:** Product Spec
**Author(s):** Advantech
**Date:** 2026
**Origin:** raw/MIC-series/MIC-760.md

## Summary

The MIC-760 is Advantech's compact fanless controller system purpose-built for AMR (Autonomous Mobile Robot) and MMR (Material Movement Robot) applications. It uses 12th/13th/14th Gen Intel Core i processors (LGA1700 socket) with isolated DIO, CANbus, and serial ports for industrial communication, plus three Ethernet ports for camera and LiDAR connectivity. It ships with Ubuntu 22.04 / Advantech Edge Linux and ROS2 support out of the box.

## Key Points

- CPU: Intel 12th/13th/14th Gen Core i, LGA1700 socket
- Fanless design; rated up to 60°C operating temperature
- ESD protection: Contact 8KV / Air 15KV, Class IV level
- EMI: Class B design
- I/O: 3× Ethernet, 4× USB 3.2 (5Gbps Gen1)
- Industrial communication: Isolated DIO, CANbus, Serial ports
- Industrial WiFi with fast roaming at 36ms
- OS: Ubuntu 22.04 and Advantech Edge Linux
- ROS2 package ready (EtherCAT node and Modbus node support)
- Compact size optimized for AMR/MMR installation
