# MIC-770 V2

**Type:** Product Spec
**Author(s):** Advantech
**Date:** 2026 (10th Gen platform)
**Origin:** raw/MIC-series/MIC-770 V2.md

**Sub-series:** [[MIC-770x]]

## Summary

The MIC-770 V2 upgrades the MIC-770 line to Intel 10th Gen Xeon/Core i processors (LGA1200), improving operating temperature by 10°C to -10~50°C, and adding FlexIO/iDoor expansion, RED compliance, and cloud platform certifications (Azure PnP, AWS IoT Greengrass, Ubuntu Certified). The chassis dimensions are identical to V1.

## Key Points

- CPU: Intel 10th Gen Xeon/Core i, LGA1200 socket, up to 65W TDP, up to 10 cores, up to 20MB L3
- SKUs: MIC-770H-20A1 (H420E chipset), MIC-770W-20A1 (W480E chipset)
- Memory: DDR4 2666/2933MHz, 64GB max, 2× 260-pin SO-DIMM
- Storage: 1× 2.5" internal HDD/SSD + 1× mSATA; W480E adds RAID 0/1/5/10
- Display: 1× VGA + 1× HDMI
- LAN: 2× GbE RJ45 (H420E: I219V + I210IT; W480E: I219-LM + I210-IT)
- COM: 2× RS-232/422/485 (auto flow control) + 4× RS-232 optional
- USB: H420E = 4× USB 3.2 Gen1 + 4× USB 2.0; W480E = 2× USB 3.2 Gen2 + 6× USB 3.2 Gen1 + 1× USB 2.0 internal
- Mini PCIe: H420E = 1 slot; W480E = 2 slots
- Audio: 1× Line-out + 1× Mic-in
- Watchdog: Programmable 1–255 sec/min
- Power: 9~36 VDC (ATX, AT)
- Operating temp: -10~50°C with 0.7m/s airflow (+10°C vs V1)
- Non-operational: -40~85°C
- Operating shock: 20G, IEC-68-2-27, half-sine, 11ms (with SSD)
- Dimensions: 77 × 192 × 230 mm, 2.8 kg (identical to V1)
- RED Compliance; Microsoft Azure PnP certified; AWS IoT Greengrass certified; Ubuntu Certified
- Supports i-Modules, FlexIO, iDoor technology
