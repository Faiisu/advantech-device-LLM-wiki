# MIC-770 V3

**Type:** Product Spec
**Author(s):** Advantech
**Date:** 2026 (12th–14th Gen platform)
**Origin:** raw/MIC-series/MIC-770 V3.md

**Sub-series:** [[MIC-770x]]

## Summary

The MIC-770 V3 is a major generational upgrade, shifting to Intel 12th–14th Gen Core processors (LGA1700) with DDR5 memory, an added NVMe M.2 slot, IP40 dust protection, and iBMC 1.2 out-of-band management. Two chassis widths (77mm and 107.3mm) accommodate different i-Module configurations. Coldest operating start point improves to -20°C.

## Key Points

- CPU: Intel 12th/13th/14th Gen Core i, LGA1700 socket, up to 65W TDP, up to 24 cores, up to 30MB L3
- Chipset: R680E (high-end, RAID, 2× mini PCIe) or H610E (mainstream, no RAID, 1× mini PCIe)
- Memory: DDR5 4800MHz, 128GB max, 2× 262-pin SO-DIMM (64GB per slot)
- Storage: 1× 2.5" HDD/SSD + 1× mSATA + 1× NVMe M.2 2280 (PCIe Gen4 x4, M-Key); R680E adds RAID 0/1/5/10
- Display: 1× VGA + 1× HDMI
- LAN: 2× GbE RJ45 (I219-LM + I210-IT on R680E; I219-V + I210-IT on H610E)
- COM: 2× RS-232/422/485 (auto flow control) + 4× RS-232 optional
- USB: R680E = 2× USB 3.2 Gen2 + 6× USB 3.2 Gen1 + 1× USB 2.0 internal; H610E = 4× USB 3.2 Gen1 + 4× USB 2.0
- Audio: 1× Line-out + 1× Mic-in
- IP40 dust proof — enhanced vs V1/V2
- Operating temp: -20~50°C with 0.7m/s airflow; -20~35°C without airflow
- Non-operational: -40~85°C
- Operating shock: 20G, IEC-68-2-27, half-sine, 11ms (with SSD)
- Dimensions: 77×192×230mm (H610E/narrow, 2.8 kg) or 107.3×192×230mm (R680E/wide, 4.65 kg)
- Mounting: Desktop, Wall mount
- Certs: CE/FCC Class A, CCC, BSMI, UL/CB
- Features: Intel vPro/AMT support, TPM support, iBMC 1.2 remote out-of-band management (via WISE-DeviceOn)
- OS: Windows 11 IoT Enterprise LTSC supported
- Supports FlexIO, iDoor, i-Modules, SUSI API
