# ARK-6322

**Type:** Product Specification Sheet  
**Author(s):** Advantech  
**Origin:** `raw/ARK-6322.md` | https://www.advantech.com/th-th/products/ark_6300_series_mini-itx_series_embedded_ipcs/ark-6322/mod_2bb991c2-e9a5-4e7c-8671-ab2ca7cb646c

## Summary

The ARK-6322 is a fanless embedded box PC from Advantech, built on the Intel Celeron J1900 quad-core SoC. It is designed for industrial and edge deployments where passive cooling, wide-temperature operation, and rich serial I/O are required. Part of the ARK-6300 Mini-ITX series.

## Key Points

- **CPU:** Intel Celeron J1900 quad-core, 2.0 GHz (Turbo up to 2.41 GHz), 2 MB L2 cache
- **Memory:** Up to 8 GB DDR3L 1333 MHz via 2x 204-pin SO-DIMM; no ECC
- **Graphics:** Intel Gen 7 integrated GPU (688 MHz); dual display VGA + DisplayPort; 224 MB shared VRAM
- **Serial I/O:** 5x RS-232 + 1x RS-232/422/485 (software configurable) = **6x COM total** — strong industrial profile
- **USB:** 1x USB 3.0 + 7x USB 2.0 = 8x USB total
- **Networking:** 2x Gigabit Ethernet (Realtek RTL8111E)
- **GPIO:** 8-bit
- **Storage:** 1x 2.5"/3.5" SATA HDD bay + 1x mSATA (shared with Mini PCIe slot)
- **Expansion:** 1x full-size + 1x half-size Mini PCIe (supports WWAN and WLAN modules)
- **Power:** 12 VDC input; typical 15.7W, max 24.7W; lockable DC jack
- **Thermal:** 0–50°C operating (with SSD), 0–40°C with 3.5" HDD; requires 0.7 m/s airflow
- **Dimensions:** 200 × 64 × 200 mm; 2.0 kg; aluminum housing
- **OS:** Windows 10/8/7, WES8/WES7; Linux by project
- **Certifications:** CE/FCC Class A, CCC, BSMI, CB, UL; **no RED certification**
- **Watchdog timer:** 255-level software-configurable

## Notable Details

- Lockable DC jack prevents accidental power disconnection in field deployments
- No RED certification — not approved for wireless regulatory compliance in EU/certain markets as-is
- BIOS default is 64-bit OS; 32-bit OS BIOS requires project-level customization
- Optional iDoor modules allow additional I/O expansion without external adapters
