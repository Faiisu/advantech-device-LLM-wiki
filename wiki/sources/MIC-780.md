# MIC-780

**Type:** Product Spec
**Author(s):** Advantech
**Date:** 2026
**Origin:** raw/MIC-series/MIC-780.md

**Sub-series:** [[MIC-78x]]

## Summary

The MIC-780 is Advantech's first fanless industrial box PC featuring Intel Core Ultra Processors (Series 2, LGA1851) with an integrated NPU for on-device AI inference. It offers DDR5 6400MHz memory, three simultaneous display outputs (DP + 2× HDMI), and DIN rail mounting support. Two SKUs differ in GbE count and USB speed.

## Key Points

- CPU: Intel Core Ultra 5/7/9 Processors Series 2, LGA1851 socket, up to 65W TDP, up to 24 cores, up to 36MB L3
- Chipset: W880 (MIC-780W) or H810 (MIC-780H)
- Graphics: Intel Xe LPG with integrated NPU — first fanless industrial box PC with integrated NPU per Advantech
- Memory: DDR5 6400MHz, 128GB max, 2× 262-pin SO-DIMM (64GB per slot)
- Storage: 2× 2.5" HDD/SSD + 1× NVMe M.2 2280 (PCIe Gen4 x4, M-Key) + 1× mini-PCIe
- Display: 3 outputs simultaneously — 1× DisplayPort + 2× HDMI
- LAN: MIC-780W = 4× GbE (I219-LM + I210-IT); MIC-780H = 2× GbE (I219-LM + I210-IT)
- COM: 2× DB9 RS-232/422/485 (auto flow control) + 4× RS-232 optional (98R17500601)
- USB: both SKUs = 2× USB 3.2 Gen2 (10G) + 2× USB 3.2 Gen1 (5G) + 1× USB 2.0 internal
- Audio: 1× Line-out + 1× Mic-in
- Watchdog: Programmable 1–255 sec/min
- Power: 12~36 VDC (ATX, AT) — note: minimum 12V vs 9V on MIC-770 series
- Operating temp: -20~50°C with 0.7m/s airflow
- Non-operational: -40~85°C
- Operating shock: 20G, IEC-68-2-27, half-sine, 11ms (with SSD)
- Dimensions: 195 × 80 × 240 mm, 3.8 kg — wider form factor than MIC-770 series
- Mounting: Desktop, Wall mount, DIN rail mount
- Certs: CE/FCC Class A, CCC, BSMI, UL/CB
- Expansion: via MIC-78 series i-Module (dedicated series; not backward-compatible with MIC-770 i-Modules)
