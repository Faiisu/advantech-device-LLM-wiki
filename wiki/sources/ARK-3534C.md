# ARK-3534C

## Summary

The ARK-3534C is the first ARK-3000 model on the 12th/13th/14th Gen Intel Core LGA1700 platform (Alder/Raptor Lake). It introduces DDR5, CAN Bus, and IEC 62443-4-2 SL2 to the ARK-3000 expansion tier. Uses Intel H610E chipset with 2× GbE (1× standard + 1× 2.5GbE); no ECC. The spec sheet is noticeably sparse — operating temperature, power consumption, and GPIO are absent from the spec table (though mentioned in the feature list). Likely an incomplete spec sheet rather than capability gap.

## Key Points

- **CPU:** Intel 12/13/14th Gen 65W Embedded Series; LGA1700; Intel H610E chipset
- **Memory:** DDR5 4800 MHz, up to 64 GB, 2× 262-pin SO-DIMM; **no ECC**
- **Display:** 2× HDMI + optional 3rd (no VGA — first ARK-3000 model without VGA)
- **LAN:** 2× — Intel I219-LM GbE + Intel i225 2.5GbE
- **COM:** 4× RS-232/422/485 auto-flow (base) + optional COM7/8 (2× RS-232) = up to 6 total
- **USB:** 4× USB 3.2 (2× Gen2 + 2× Gen1) + 4× USB 2.0
- **CAN Bus:** 2× (feature list; not in spec table)
- **GPIO:** 16-bit DIO (feature list; not in spec table)
- **TPM:** 2.0
- **Expansion:** 1× M.2 B-key (2242/3042) + 1× M.2 E-key (2230), 1× PCIe x16, 2× PCI
- **Storage:** 2× 2.5" SATAIII (up to 3× per feature list)
- **Power:** AT/ATX, 9~36 VDC; power consumption not listed in spec sheet
- **Temp:** Not listed in spec sheet
- **OS:** Windows 10 (Win 11 not listed — likely incomplete spec sheet)
- **Cert:** CE/FCC Class B, CCC, BSMI, UKCA; CB, UL, CCC, BSMI, UKCA
- **IEC 62443-4-2 SL2** conformity; supports EU Cyber Resilience Act compliance
- **SW:** SUSI API, WISE-DeviceOn, McAfee, Acronis bundled
