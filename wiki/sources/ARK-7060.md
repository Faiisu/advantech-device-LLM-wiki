# ARK-7060

## Summary

The ARK-7060 is Advantech's "Extreme Performance Box PC" in the ARK-7000 series. Powered by 2nd Gen Intel Xeon D-1700 (Ice Lake-D) with up to 10 cores, it targets demanding edge compute and server workloads. Key distinctions from all other ARK models in this wiki: **active cooling** (fan + CPU cooler), **AC power input** (100–240V AC), **IPMI 2.0** server management, **128GB DDR4 ECC**, and **optional dual 10GbE** via AMO module. No COM ports listed. Available in two SKUs: U0A1 (10-core D-1746TER, 67W) and U4A1 (4-core D-1715TER, 50W).

## Key Points

- **CPU:** Intel Xeon D-1746TER (10C/67W) or D-1715TER (4C/50W); Ice Lake-D embedded server platform
- **Memory:** DDR4 2933MHz, up to **128GB ECC**, 4× 260-pin SO-DIMM — highest capacity in this wiki
- **Display:** 1× VGA (via Aspeed AST2500 BMC)
- **LAN:** 2× Intel i210 GbE (standard) + optional 2× 10GbE via Intel X550 (AMO-I031); 1× dedicated GbE management port (IPMI)
- **COM:** Not listed in spec sheet (notable absence vs all other ARK series)
- **USB:** 4× USB 3.0
- **CAN Bus:** None
- **GPIO:** Not listed
- **TPM:** Optional (AMO-I029)
- **Expansion:** 2× M.2, 1× PCI, 1× PCIe x4, **1× PCIe x16** (GPU up to 350W)
- **Storage:** 2× 2.5" SATAIII (up to 4× per feature list)
- **Cooling:** **Active — 1× system fan (120×120×38mm) + 1× CPU cooler** — NOT fanless
- **Power:** ATX, 100–240V AC (standard AC input — not DC wide-range)
- **Temp:** -10~50°C (with extended temp peripherals, 0.7 m/s airflow required)
- **Storage temp:** -40~85°C
- **Dimensions:** 230×205×390mm, 9.7kg — largest model in this wiki
- **Mounting:** Wall mounting only
- **OS:** Windows Server, Windows 10; Ubuntu 20.04
- **Management:** IPMI 2.0 (Aspeed AST2500 BMC), console port
- **Power consumption:** U4A1: 62.7W typical / 83.6W max; U0A1: TBD

## Connections to Existing Wiki

- ARK-7060 is the only **fan-cooled** model in this wiki — breaks the fanless assumption of all other ARK series.
- ARK-7060 is the only model with **AC power input** — all others use DC wide-range (9–36V or similar).
- **128GB ECC DDR4** — surpasses ARK-3532B/C (64GB DDR4 ECC) and ARK-3534D (64GB DDR5 ECC).
- **IPMI 2.0** — no other ARK model in this wiki has server-grade out-of-band management.
- **No COM ports** — only ARK model with zero RS-232/422/485 ports listed.
- PCIe x16 GPU slot joins [[ARK-3532B]] as the only other model with this feature, but ARK-7060 supports up to 350W GPU vs ARK-3532B's unspecified limit.
- Optional 10GbE (Intel X550) via AMO-I031 — first 10GbE capable model in this wiki.
