# MIC-770

**Type:** Product Spec
**Author(s):** Advantech
**Date:** 2026 (8th/9th Gen platform)
**Origin:** raw/MIC-series/MIC-770.md

**Sub-series:** [[MIC-770x]]

## Summary

The MIC-770 (V1) is Advantech's compact fanless box PC for Intel 8th/9th Gen Core processors (LGA1151), available in two chipset variants: H310 (consumer/value — MIC-770H) and Q370 (business/vPro — MIC-770Q). Designed for desktop and wall-mount deployments with i-Module expansion support and SUSIAccess APIs.

## Key Points

- CPU: Intel 8th/9th Gen Core i, LGA1151 socket, up to 65W TDP, up to 8 cores, up to 12MB L3
- SKUs: MIC-770H-00A2 (H310 chipset), MIC-770Q-00A2 (Q370 chipset)
- Memory: DDR4 2400/2666MHz, 64GB max, 2× 260-pin SO-DIMM
- Storage: 1× 2.5" internal HDD/SSD + 1× mSATA; Q370 adds RAID 0/1/5/10
- Display: 1× VGA + 1× HDMI
- LAN: 2× GbE RJ45 (H310: I219-V + I210-IT; Q370: I219-LM + I210-IT)
- COM: 2× RS-232/422/485 (auto flow control) + 4× RS-232 optional
- USB: H310 = 4× USB 3.0 + 4× USB 2.0; Q370 = 2× USB 3.1 + 6× USB 3.0 + 1× USB 2.0 internal
- Mini PCIe: H310 = 1 slot; Q370 = 2 slots
- Audio: 1× Line-out + 1× Mic-in
- Watchdog: Programmable 1–255 sec/min, system reset output
- Power: 9~36 VDC (ATX, AT)
- Operating temp: -10~40°C with 0.7m/s airflow
- Non-operational: -40~85°C
- Operating shock: 20G, IEC-68-2-27, half-sine, 11ms (with SSD)
- Dimensions: 77 × 192 × 230 mm, 2.8 kg
- Mounting: Desktop, Wall mount
- Certs: CE/FCC Class A, CCC, BSMI, UL/CB
- Supports i-Modules, SUSIAccess, Advantech embedded software APIs
