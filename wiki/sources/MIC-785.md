# MIC-785

**Type:** Product Spec
**Author(s):** Advantech
**Date:** 2026
**Origin:** raw/MIC-series/MIC-785.md

**Sub-series:** [[MIC-78x]]

## Summary

The MIC-785 is Advantech's first AMD-based compact fanless box PC in the MIC series, supporting AMD Ryzen Embedded 7000/9000 and EPYC 4005 processors on the AM5 (LGA1718) socket. It shares the MIC-770/780 one-side-IO chassis design philosophy and targets machine vision and high-performance machine controller applications where AMD's CPU/GPU compute is preferred.

## Key Points

- CPU: AMD Ryzen Embedded 7000/9000 series and AMD EPYC 4005, AM5 socket (LGA1718)
- Multiple independent display outputs (count not specified in raw)
- Storage: 2× 2.5" HDD/SSD + 1× NVMe M.2
- Power: 12~36 VDC input range
- I/O: GbE, USB 3.2, COM ports (counts not specified in raw)
- One-side IO design — shared industrial cabling philosophy with MIC-770/780 chassis family
- Supports FlexIO, iDoor, and i-Module expansion
- Software: Advantech SUSI API and embedded software APIs
- Out-of-band management: iBMC 1.2 technology
- Target use: machine vision, high-end machine controller applications
