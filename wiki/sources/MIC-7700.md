# MIC-7700

**Type:** Product Spec
**Author(s):** Advantech
**Date:** 2026 (legacy 6th/7th Gen platform)
**Origin:** raw/MIC-series/MIC-7700.md

**Sub-series:** [[MIC-770x]]

## Summary

The MIC-7700 is the legacy predecessor of the MIC-770 line, using Intel 6th/7th Gen Core i Desktop processors (LGA1151 socket) with Q170 or H110 chipset. Notable for DVI output (not HDMI) and a CFast storage slot, it is the oldest MIC-series model in this wiki and has been superseded by the MIC-770 V1 through V3 series.

## Key Points

- CPU: Intel 6th/7th Gen Core i Desktop, LGA1151 socket
- Chipset: Q170 or H110
- Display: VGA + DVI (legacy; no HDMI — unique in MIC-770 line)
- LAN: 2× GbE
- USB: 8× USB 3.0
- COM: 2× RS-232/422/485 + 4× RS-232 (with expansion cable)
- Storage: 1× 2.5" HDD + 1× CFast + 1× mSATA + 1× mini-PCIe slot with SIM card support
- Power: 9~36V DC wide-range input
- Wide operating temperature (specific range not specified in raw data)
- Supports i-Module, SUSIAccess, embedded software APIs

## Connections to Existing Wiki

- ARK-3520L also uses Intel 6th Gen Core (Skylake-H BGA); MIC-7700 uses socketed LGA1151 desktop — different CPU segment, same era
- MIC-7700 is the only MIC-series model with DVI output; all successors (MIC-770 V1+) switched to HDMI
- CFast slot is unique to MIC-7700 in this wiki — industrial solid-state storage format absent from all other models
- mini-PCIe with SIM slot enables cellular connectivity option not listed for other MIC-770 variants
- Replaced by [[MIC-770]] which added HDMI, dropped DVI/CFast, and gained 8th/9th Gen CPU support
