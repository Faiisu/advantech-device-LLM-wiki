# SUSIAccess

## Definition

Advantech's embedded software management layer and API suite for remote monitoring and management of Advantech hardware. Provides standardized access to hardware-level features (watchdog, GPIO, thermal monitoring, backlight control, etc.) via a unified software interface.

## Why It Matters

Standardizes hardware feature access across Advantech product families, allowing application software to control hardware functions without low-level driver development.

## Relationship to DeviceOn

SUSIAccess appears in older ARK models (e.g., ARK-1123H), while [[DeviceOn]] appears in newer ones. It is unclear from the current sources whether SUSIAccess is a component of DeviceOn or a predecessor platform. Flagged as an open question.
