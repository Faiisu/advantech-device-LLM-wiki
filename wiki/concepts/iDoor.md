# iDoor

## Definition

Advantech's proprietary modular I/O expansion system. iDoor modules plug into a dedicated slot on compatible Advantech embedded PCs, adding serial ports, isolated DIO, CAN bus, fieldbus, or wireless interfaces without requiring external boxes or PCIe cards.

## Why It Matters

Enables I/O expansion in a compact, integrated form factor — the module fits within the existing chassis footprint. Useful when the base platform's built-in I/O is insufficient and adding an external expansion box is impractical.

## Known Module Types

- Additional COM ports (RS-232/422/485)
- Isolated digital I/O
- CAN bus
- Fieldbus (Profibus, PROFINET, EtherCAT)
- Wireless (Wi-Fi, LTE)
