# ARK-3534x Sub-series Hub

**Part of:** [[Advantech]] ARK-3000 Series  
**Members:** [[ARK-3534C]], [[ARK-3534D]]  
**Prompted by:** Batch ingest of ARK-3000 series.  
**Type:** Comparison + Selection Guide

## Overview

Both models share the 12th/13th/14th Gen Intel Core LGA1700 platform with DDR5, dual HDMI triple-display, 2× CAN Bus, TPM 2.0, and IEC 62443-4-2 SL2 certification. The key split is chipset: ARK-3534C uses H610E (no ECC, 2× GbE), while ARK-3534D uses R680E (ECC DDR5, 4× GbE, PCIe x4 slot, SW RAID). ARK-3534D is the higher-reliability variant; ARK-3534C is the entry model.

## Shared Characteristics

- 12th/13th/14th Gen Intel Core LGA1700, 65W embedded series (CPU upgradeable)
- DDR5 4800MHz up to 64GB — latest memory standard in this wiki's ARK lineup
- 2× HDMI triple-display (no VGA — first ARK-3000 models without VGA)
- 2× CAN Bus — matches ARK-1125H for most CAN ports in compact tier; important for automotive/robotics
- TPM 2.0, IEC 62443-4-2 SL2, WISE-DeviceOn, SUSI API bundled on both
- Supports EU Cyber Resilience Act compliance via IEC 62443-4-2 SL2
- Wide-range 9~36 VDC input
- Fanless passive cooling chassis (sheet metal + aluminum top cover)

## Key Distinctions

> **ECC vs no ECC:** The chipset choice (R680E vs H610E) is the single biggest difference. ECC DDR5 on ARK-3534D prevents silent memory corruption — essential for any application processing financial, medical, or safety-critical data. If ECC matters, ARK-3534D is the only choice.

> **4× GbE vs 2× GbE:** ARK-3534D's 3× Intel i225 2.5GbE ports (plus 1× standard GbE) enable simultaneous connection to multiple network segments — OT network, IT network, management network, and a fieldbus gateway — without a managed switch.

> **ARK-3534C spec sheet appears incomplete:** Operating temperature, power consumption, and GPIO are absent from the spec table (only in feature bullets). Windows 11 is also missing while ARK-3534D lists it. Treat ARK-3534C spec sheet figures as minimum confirmed — actual capabilities likely match ARK-3534D more closely.
