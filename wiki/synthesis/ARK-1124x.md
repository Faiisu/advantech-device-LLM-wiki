# ARK-1124x Sub-series

**Part of:** [[Advantech]] ARK-1000 Series  
**Type:** Sub-series Overview + Selection Guide  
**Members:** [[ARK-1124C]], [[ARK-1124H]]

## Overview

Two DIN-rail fanless box PCs sharing the same 133×46.4×94.2mm chassis (slightly wider than ARK-1123x at 46.4mm vs 43.1mm). Both are Apollo Lake generation with iDoor expansion support. The "C" variant prioritises COM ports; the "H" variant prioritises display output and security. Key upgrade point: ARK-1124H moves to a quad-core E3940 while ARK-1124C uses the dual-core N3350.

## Shared Characteristics

- Form factor: 133 × 46.4 × 94.2 mm (both identical)
- DIN-rail / Wall / VESA mounting
- iDoor 2nd-layer expansion slot
- Max RAM: 8 GB via 1× SO-DIMM
- Storage: 1× 2.5" SATA HDD bay + 1× half-size mSATA
- Operating temp: -20–60°C (extended); 0–40°C with HDD
- Power: 12 VDC, lockable DC jack
- OS: Windows 10 / Linux by project

---

## Key Distinctions to Remember

- **ARK-1124C** is the COM-heavy model — 4 serial ports but only 1 GbE. Targets serial-heavy field devices.
- **ARK-1124H** trades COM ports (only 1) for dual HDMI + TPM 2.0 + RED path. Targets display + security use cases.
- RED certification on ARK-1124H is only available on the **single-layer SKU** — iDoor dual-layer configuration loses the RED path.
- Both support iDoor expansion, but ARK-1124H additionally has M.2 E key for WiFi (dual wireless path).
