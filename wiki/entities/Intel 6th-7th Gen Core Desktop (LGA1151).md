# Intel 6th-7th Gen Core Desktop (LGA1151)

**Type:** Processor
**Also known as:** Skylake (6th Gen), Kaby Lake (7th Gen); LGA1151 v1 socket; desktop socketed platform

## Overview

Intel 6th and 7th Generation Core desktop processors use the original LGA1151 socket (v1) with Skylake or Kaby Lake microarchitecture. The platform supports DDR4 2133/2400MHz dual-channel memory. Chipsets include H110 (value), Q170 (business/vPro), and Z170/Z270 (enthusiast). This platform is now legacy / end-of-life.

## Key Facts

- Socket: LGA1151 v1 (electrically incompatible with 8th/9th Gen LGA1151 v2 boards)
- TDP: up to 65W (desktop 65W-class)
- Cores: up to 4 (mainstream desktop; HEDT variants separate)
- Memory: Dual-channel DDR4 2133/2400MHz
- Chipsets used in MIC-7700: Intel Q170 (business/vPro), Intel H110 (value)
- Legacy status: no longer in active Intel embedded roadmap

## Role in This Wiki

Used exclusively in the [[MIC-7700]], the oldest MIC-series model in this wiki. Distinct from [[Intel 6th Gen Core (Skylake-H)]] used in the ARK-3520L, which is a BGA (soldered) mobile/embedded variant (Skylake-H, 45W quad-core) vs this socketed desktop platform (65W, LGA1151).
